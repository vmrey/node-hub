# 部署指南

### 方式一：Cloudflare 控制台直接部署（推荐，无需本地环境）

1. **创建 Worker**：
   - 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，进入 **Workers 和 Pages**。
   - 点击 **创建应用程序** -> **创建 Worker** -> 点击 **部署**。

2. **粘贴代码**：
   - 打开项目中的 **`_worker.js`** 文件并复制全部内容。
   - 在刚才创建的 Worker 页面中，点击右上角 **编辑代码**。
   - 清空编辑器原有代码，粘贴 `_worker.js` 内容并点击 **部署**。

3. **绑定 KV 命名空间**：
   - 在 Cloudflare 控制台左侧菜单进入 **存储与数据库** -> **KV** -> 点击 **创建命名空间**，名称填写 `KV`。
   - 返回刚才创建的 Worker 页面，进入 **设置** -> **变量与机密**。
   - 在 **KV 命名空间绑定** 区域点击 **添加绑定**：
     - 变量名称必须严格填写为：`KV`
     - KV 命名空间选择刚创建的 `KV`。

4. **配置管理员密码**：
   - 在同一页面的 **环境变量与机密** 区域，点击 **添加**：
     - 变量名称：`ADMIN`
     - 变量值：设置您的后台登录密码
     - 类型请勾选 **机密 (Secret)** 进行加密保护。
   - 点击 **保存并部署**，即可通过分配的 Worker 域名访问后台。

---

### 方式二：命令行自动化部署（适合已有 Node.js 环境）

```bash
# 1. 安装依赖
npm install

# 2. 登录 Cloudflare 账号
npx wrangler login

# 3. 执行一键自动化部署脚本（自动创建并绑定 KV、发布代码）
npm run deploy
```
