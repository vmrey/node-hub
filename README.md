# ⚡ Node Hub (节点与订阅管理中枢)

原生兼容 **Cloudflare Pages** 与 **Cloudflare Workers** 双平台的 VLESS 节点管理与订阅中枢。

---

## 📋 环境变量一览

| 变量名 | 类型 | 必须 | 适用平台 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| **`KV`** | KV 命名空间绑定 | **是** | Pages & Workers | 系统存储空间，用于保存节点、订阅与配置数据。 |
| **`ADMIN`** | 环境变量 | **是** | Pages & Workers | 后台管理登录密码（建议设置为强密码）。 |
| **`KV_ID`** | 构建环境变量 | Workers 自动发包需配置 | **仅限 Workers** | 您在控制台创建的 32 位 KV 真实 ID。配置在【构建环境变量】中，可阻止发包时 Cloudflare 强制解绑 KV。*(Pages 用户完全无需此变量)* |

---

## 🚀 部署教程（推荐方案一）

### 🌟 方案一：Cloudflare Pages 部署（推荐 ⭐⭐⭐⭐⭐）

> **核心优势**：在控制台绑定一次，以后推送到 GitHub 每次都会**全自动注入**，终身**永不掉绑定**，且无需配置任何 `KV_ID`。

#### 1. 创建 KV 存储与连接仓库
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，在左侧侧边栏进入 **存储与数据库 -> KV**，点击 **创建命名空间**，名称填写 `KV`。
2. 返回左侧进入 **Workers 和 Pages** -> 点击 **创建** -> 选择 **Pages** -> **连接到 Git**。
3. 选择本项目 `node-hub` 仓库：
   - **构建命令**：`npm run build`
   - **构建输出目录**：留空（或填 `/`）
   - 点击 **保存并部署**。

#### 2. 绑定 KV 与设置管理密码（仅需一次）
1. 部署完成后，进入该 Pages 项目的 **设置 (Settings) -> 函数 (Functions)**：
   - 下滑找到 **KV 命名空间绑定**，点击 **添加绑定**：
     - **变量名称**：`KV`
     - **KV 命名空间**：选择刚才创建的 `KV`
2. 点击 **设置 (Settings) -> 环境变量 (Environment variables)**：
   - 点击 **添加变量**：
     - **变量名称**：`ADMIN`
     - **值**：输入您的后台登录密码
3. **完成！** 访问 Pages 域名即可直接进入后台。以后只要向 GitHub 提交代码，系统将自动全量更新且绑定永不丢失！

---

### ⚡ 方案二：Cloudflare Workers 部署

> **注意**：Workers 的 Git 部署会在发包时根据配置文件全量覆盖。为了防止自动发包抹除控制台的 KV 绑定，请务必配置一次 `KV_ID` 构建变量。

#### 1. 创建 Worker 并关联 GitHub
1. 在控制台进入 **Workers 和 Pages** -> 点击 **创建** -> **Worker** -> 命名后点击部署。
2. 进入该 Worker -> **设置 (Settings) -> 构建 (Build)** -> 点击 **连接 Git (Connect Git)** 并选择本仓库。

#### 2. 配置构建变量与绑定（锁定绑定）
1. 在 **存储与数据库 -> KV** 中，复制 `KV` 命名空间的 **32 位真实 ID**。
2. 进入该 Worker **设置 -> 构建 (Build) -> 构建环境变量**，添加：
   - 变量名称：`KV_ID`
   - 变量值：填入刚才复制的 32 位 ID
3. 进入该 Worker **设置 -> 变量与机密 (Variables and Secrets)**：
   - **环境变量**：添加 `ADMIN`（管理密码）。
   - **KV 命名空间绑定**：添加绑定，变量名称填 `KV`，选择对应的 KV 空间。
4. 点击 **保存并部署**。

### 💻 方案三：本地命令行一键部署（CLI）

适合本地已安装 Node.js 环境的开发者，脚本全自动检测/创建 KV 并完成发布：

```bash
# 1. 安装依赖
npm install

# 2. 登录授权 Cloudflare 账号
npx wrangler login

# 3. 一键全自动创建 KV 并部署到云端
npm run deploy
```
